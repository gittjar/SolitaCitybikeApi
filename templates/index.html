API Reference

REST API
GET /api/stations

Get all stations with optional filtering and sorting

?city=Helsinki
?sort_by=Kapasiteet & order=DESC
GET /api/cities

Get list of all unique cities

GET /api/stations/{text}

Search stations by name (partial match)

GET /api/station/{id}

Get specific station by ID

POST /api/stations

Create a new station

Content-Type: application/json
PUT /api/station/{id}

Update existing station

Content-Type: application/json
DELETE /api/station/{id}

Delete station permanently

→

All endpoints return JSON responses. Authentication not required.
